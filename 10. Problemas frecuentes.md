| Síntoma                                                   | Causa                                                                          | Solución                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Mi Logic App no sale en la lista de playbooks de la regla | Trigger de la regla distinto al de la Logic App                                | Usa regla de tipo **incidente** con trigger _Sentinel incident_             |
| El desplegable "Área de trabajo" sale vacío               | Unified RBAC activo sin roles                                                  | Ver creación y permisos                                                     |
| No pasa nada al generar la alerta                         | Condición de la regla que no coincide, o el incidente se agrupó en uno abierto | Quita o ajusta la condición (**Contiene**) y cierra los incidentes abiertos |
| Se ejecuta pero falla el HTTP                             | PC, Ollama o ngrok apagados; URL de ngrok cambiada                             | Reinicia el túnel y actualiza la URI                                        |
| HTTP con `403`                                            | Ollama rechaza la cabecera Host                                                | `ngrok http 11434 --host-header="localhost:11434"`                          |
| Falla por tiempo de espera                                | El modelo tarda demasiado (la acción HTTP tiene un límite de unos 2 minutos)   | Usa un modelo más pequeño o reduce los datos enviados                       |
| Guardar el código da error de JSON                        | Falta o sobra una llave o una coma                                             | Ver creación interna de la app                                              |
| El comentario muestra `###`, `**` o vallas de código      | Sentinel no interpreta Markdown                                                | Usa los `replace(...)` del campo `message`                                  |
| No encuentro el comentario                                | No aparece en la cabecera del incidente                                        | Mira la pestaña **Actividades**                                             |
