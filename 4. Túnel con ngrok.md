Azure necesita una URL pública para llegar a tu PC.

1. Crea una cuenta en [https://ngrok.com](https://ngrok.com) e instala el cliente.
2. Registra tu token (lo encuentras en el panel de ngrok):

bash

```bash
   ngrok config add-authtoken <TU_TOKEN>
```

3. Abre el túnel hacia Ollama:

bash

```bash
   ngrok http 11434
```

4. Anota la URL `https://<TU_DOMINIO>.ngrok-free.dev` que aparece en _Forwarding_. Tu endpoint será:

text

```text
   https://<TU_DOMINIO>.ngrok-free.dev/api/generate
```

5. Pruébalo desde fuera de tu red (o al menos desde otra terminal):

bash

```bash
   curl https://<TU_DOMINIO>.ngrok-free.dev/api/generate -d '{"model":"<tu_modelo>","prompt":"Di hola","stream":false}'
```

Si Ollama responde `403 Forbidden`, reescribe la cabecera Host al abrir el túnel:

bash

```bash
ngrok http 11434 --host-header="localhost:11434"
```

### Seguridad del túnel

- Cualquiera que conozca la URL puede usar tu Ollama: no la publiques ni la subas a GitHub.
- Los datos del incidente **pasan por los servidores de ngrok** aunque el modelo sea local.
NO pasar datos reales por este tune ya que viaja en texto plano a los sevidores de ngrok. 
- Cierra el túnel cuando no estés probando.
- **Con el plan gratuito, el PC, Ollama y ngrok deben estar encendidos cuando salte un incidente; si no, la ejecución de la Logic App falla.**

> [!important]
> Si usas ngrok, los datos inevitablemente pasarán por su servidor. Para lograr "gratuito" y "no pasar por terceros", la esencia es **construir tu propia versión de ngrok**. Necesitas una VPS con IP pública, desplegar un software de túnel de código abierto (como `gotunnel`[](https://libraries.io/go/github.com%2Fbakare-dev%2Fgotunnel#1), `proxvn_tunnel`[](https://socket.dev/go/package/github.com/hoangtuvungcao/proxvn_tunnel_full?version=v7.5.0%2Bincompatible#1)[](https://github.com/hoangtuvungcao/proxvn_tunnel_full/blob/main/README.md#1#1) o `Octelium`[](https://github.com/octelium/octelium?cmid=8721d5f1-eddf-486e-b21e-3d85704bea82#1)) en ella, y luego conectar tu servicio local a tu propio servidor.
