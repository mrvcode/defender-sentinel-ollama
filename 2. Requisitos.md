- Suscripción de Azure y un workspace de Log Analytics con **Microsoft Sentinel** activado.
- Workspace conectado al **portal de Microsoft Defender** (`security.microsoft.com`).
- Un equipo de pruebas incorporado a **Defender for Endpoint** (para generar alertas reales).
- Un PC con suficiente RAM para el modelo elegido (Ollama + Ai) y, si usas Windows, **WSL2** (opcional).
- Cuenta gratuita de **ngrok**(para el túnel).
- Un usuario con permisos para crear recursos y asignar roles en el grupo de recursos (en el laboratorio: _Owner_ de la suscripción).

> [!tip]
> *La documentación esta basada en Windows 11 (Onboarding) + wsl2*
> *Tener en cuenta que ha de estar encendido tanto Ollama como el túnel elegido para que Azure pueda comunicarse.
