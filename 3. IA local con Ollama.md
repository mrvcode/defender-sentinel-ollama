1. Instala Ollama (Windows, macOS o Linux/WSL2) siguiendo la guía oficial: [https://ollama.com/download](https://ollama.com/download).
2. Descarga un modelo. Elige el tamaño según tu RAM y ten en cuenta que los modelos grandes tardan más en responder:

** El modelo es solo un ejemplo.**

bash

```bash
   ollama pull <tu_modelo>
```

3. (Opcional) Ponle un alias corto, que es el nombre que usarás en la Logic App:

bash

```bash
   ollama cp <tu_modelo> <renombra_tu_modelo>
```

4. Comprueba que responde en local:

bash

```bash
   curl http://localhost:11434/api/generate -d '{"model":"<tu_modelo>","prompt":"Di hola","stream":false}'
```

Ollama escucha por defecto en el puerto `11434`. Si lo ejecutas dentro de un contenedor o de WSL2, asegúrate de que ese puerto es accesible desde Windows. 

> Por defecto el modelo devuelve la respuesta en el campo `response`. En algunas versiones el razonamiento de los modelos va en un campo aparte (`thinking`); si en la tuya aparece dentro de `response` entre etiquetas `<think>…</think>`, tendrás que eliminarlo antes de publicar el comentario.
